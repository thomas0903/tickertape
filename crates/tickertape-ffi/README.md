# tickertape-ffi

The C ABI of [tickertape](https://github.com/thomas0903/tickertape): `libtickertape` as a shared and a static library,
and the header [`include/tickertape.h`](include/tickertape.h) (C99 and C++11), generated by cbindgen from this crate
and committed. It wraps the public API of the `tickertape` crate and adds nothing to the core.

```bash
cargo build --release -p tickertape-ffi          # target/release/libtickertape.{a,so,dylib}
cargo cinstall --release -p tickertape-ffi --prefix /usr/local   # with cargo-c: soname, header, tickertape.pc
```

Read [`docs/c-api.md`](../../docs/c-api.md) for ownership, record lifetimes, errors, threading, durability and
versioning, and [ADR 0028](../../docs/decisions/0028-c-abi.md) for the design. Examples are in
[`examples/c/`](../../examples/c/README.md). The ABI is not stable before tickertape 1.0.
